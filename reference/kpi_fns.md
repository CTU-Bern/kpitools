# Get a list of KPI summary functions provided by `kpitools`.

Get a list of KPI summary functions provided by `kpitools`.

## Usage

``` r
kpi_fns()
```

## Value

character vector of functions

## See also

kpi_fn\_

## Examples

``` r
kpi_fns()
#> [1] "kpi_fn_iqr"     "kpi_fn_max"     "kpi_fn_mean"    "kpi_fn_median" 
#> [5] "kpi_fn_min"     "kpi_fn_missing" "kpi_fn_n"       "kpi_fn_perc"   
#> [9] "kpi_fn_prop"   
```
